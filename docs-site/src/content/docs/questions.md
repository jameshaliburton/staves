---
title: "Turn questions into better work"
description: "Discuss a human consequence, then review a concrete change."
---
Select a job and open Staves to discuss it or review the workflow. Choose “Challenge this workflow” to examine assumptions one question at a time. “Not sure yet” keeps uncertainty explicit. Under **Ask the coding assistant**, **Save question** keeps a question for a coding assistant to pick up later, and **Connect assistant** is where you connect one. Start with a real concern: “What does the customer see if this answer changes?”

A useful review identifies the evidence, the consequence for someone, and what remains uncertain. It can lead to a question, a clarified outcome or a proposed change.

Questions saved on the board stay there until someone picks them up. Ask the coding agent to read `staves_issues`, investigate the relevant implementation and answer or propose a change. Review proposals before accepting or rejecting them.

**Confirmed description** means someone has accepted the account of the work. **Implementation progress** separately records unknown, planned, in progress or implemented. Neither a confident description nor a code reference proves the whole workflow is complete.
